# Modul 06: Tipografi & Token Kontras Visual (Typography & Contrast Tokens)

Modul ini menetapkan skala ukuran font presentasi, hierarki visual teks, dan rasio kontras warna tinggi (WCAG AA) untuk keterbacaan optimal di proyektor maupun monitor rapat.

---

## 1. Skala Ukuran Tipografi Slide (1920 x 1080 px Canvas)

| Elemen Tipografi | Ukuran Font Acuan | Weight | Line Height | Keterangan & Penggunaan |
| :--- | :--- | :--- | :--- | :--- |
| **Hero Metric (Angka Raksasa)**| `72pt s/d 96pt` | 800 (Extra Bold) | 1.0 | Angka persentase, pendapatan, atau data tunggal utama. |
| **Slide Action Title** | `36pt s/d 44pt` | 700 (Bold) | 1.2 | Judul kalimat aktif di bagian atas (maksimal 2 baris). |
| **Card Header / Subtitle** | `22pt s/d 28pt` | 600 (Semi Bold) | 1.3 | Judul kolom, nama pilar solusi, atau label kartu. |
| **Body Text / Kalimat Penjelas** | `16pt s/d 18pt` | 400 / 500 | 1.5 | Kalimat pendukung (maksimal 2 baris per poin peluru). |
| **Metadata / Footer / Caption** | `12pt s/d 14pt` | 400 (Regular) | 1.4 | Nomor halaman, sumber data riset, tanggal rapat. |

> Dilarang menggunakan ukuran font di bawah `14pt` pada kanvas 1080p, karena tidak akan terbaca oleh audiens di baris belakang ruang pertemuan.

## 2. Palet Warna & Token Kontras Tinggi (WCAG AA Compliant)

### 2.1 Tema "Dark Executive" (Default Paling Direkomendasikan)
- **Background Utama**: Slate-950 (`#020617`) atau Slate-900 (`#0F172A`).
- **Surface Card**: Slate-850 (`#1E293B`) dengan border tipis Slate-700 (`#334155`).
- **Teks Utama (Heading)**: Putih Bersih (`#F8FAFC`). Rasio kontras 16.5:1.
- **Teks Pendukung (Body)**: Slate-300 (`#CBD5E1`) atau Slate-400 (`#94A3B8`). Rasio kontras 9:1.
- **Warna Aksen Aksi (Primary Accent)**: Royal Blue (`#2563EB`) atau Electric Indigo (`#4F46E5`).
- **Warna Tren Positif (Success)**: Emerald Green (`#10B981`).
- **Warna Tren Negatif (Warning/Risk)**: Rose Red (`#F43F5E`).

### 2.2 Tema "Minimal Light" (Untuk Presentasi Cetak / Dokumen Board Memo)
- **Background**: Putih (`#FFFFFF`) atau Slate-50 (`#F8FAFC`).
- **Surface Card**: Abu-abu Terang (`#F1F5F9`) dengan border Slate-200 (`#E2E8F0`).
- **Teks Utama**: Slate-900 (`#0F172A`).
- **Teks Pendukung**: Slate-600 (`#475569`).
