# Modul 06: Pewarnaan 3-Roda Warna (Color Grading & Split Toning)

Modul ini menetapkan seni pewarnaan sinematik menggunakan tiga roda warna (*3-Way Color Wheels: Shadows, Midtones, Highlights*), kontrol slider *Blending*, dan titik keseimbangan (*Balance*).

---

## 1. Anatomi Tiga Roda Warna (The 3-Way Color Grading Wheels)

Pewarnaan modern memisahkan tonalitas berdasarkan zona pencahayaan:

```text
┌─────────────────────────┐  ┌─────────────────────────┐  ┌─────────────────────────┐
│     [SHADOWS WHEEL]     │  │    [MIDTONES WHEEL]     │  │   [HIGHLIGHTS WHEEL]    │
│ Mewarnai area bayangan  │  │ Mewarnai nada tengah    │  │ Mewarnai area terpapar  │
│ paling gelap & rambut   │  │ & mayoritas kulit wajah │  │ sinar lampu dan langit   │
│ Rona Khas: Teal / Cold  │  │ Rona Khas: Netral/Hangat│  │ Rona Khas: Warm Gold    │
└─────────────────────────┘  └─────────────────────────┘  └─────────────────────────┘
```

1. **Hue (Derajat Rona Lingkaran 0° - 360°)**:
   - Menentukan warna warna dasar yang disuntikkan ke dalam zona tersebut.
2. **Saturation (Panjang Jari-Jari Lingkaran 0 - 100)**:
   - Seberapa pekat warna tersebut ditambahkan. Dalam fotografi natural, nilai saturasi grading **hampir tidak pernah melebihi 20 s/d 25**.
3. **Luminance (Slider Kecerahan di Samping Roda)**:
   - Mengatur apakah zona tersebut ingin digelapkan atau diterangkan secara selektif.

---

## 2. Pengaturan Dua Slider Kunci: Blending & Balance

- **Blending (Peleburan Transisi 0 - 100)**:
  - Nilai default `50`.
  - Jika dinaikkan ke `70 s/d 80`: Transisi warna antara Shadows, Midtones, dan Highlights menjadi sangat lembut dan menyatu alami tanpa batas patah.
- **Balance (Titik Keseimbangan -100 s/d +100)**:
  - Nilai default `0`.
  - Jika digeser ke arah minus (`-20 s/d -40`): Warna pada roda **Shadows** akan mendominasi dan merambah naik ke area midtones.
  - Jika digeser ke arah plus (`+20 s/d +40`): Warna pada roda **Highlights** akan mendominasi dan merembes turun ke area nada tengah.

---

## 3. Palet Sinematik Populer (Color Palettes)
1. **Teal & Orange (Komplementer Klasik Hollywood)**:
   - Shadows: Hue `215°` (Teal Sejuk), Saturation: `12`
   - Highlights: Hue `45°` (Emas Hangat), Saturation: `15`
   - Midtones: Hue `35°` (Oranye Lembut), Saturation: `6`
2. **Vintage Nostalgia / Analog Warmth**:
   - Shadows: Hue `140°` (Hijau Zaitun Lembut), Saturation: `8`
   - Highlights: Hue `50°` (Kuning Krim), Saturation: `12`
   - Balance: `+15`
